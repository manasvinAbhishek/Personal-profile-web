01 / About

Program delivery with a technical, builder's mindset

I work at the intersection of digital public infrastructure, geospatial engineering, and implementation. My background spans requirements analysis, GIS and spatial databases, API-driven data retrieval, field operations, and large-scale government program delivery. Rather than only coordinate technology work, I also investigate data issues, design repeatable workflows, and build practical tools to solve them.

In Bihar's Digital Crop Survey ecosystem, my hands-on work includes DCS data downloading, GeoJSON map API retrieval, polygon and plot-area investigation, SQL Server spatial processing, and efforts toward an automated downloader pipeline that accommodates approximately 30-minute API token validity. I distinguish completed tools from pipeline work still being refined.
